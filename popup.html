TrueGen Password Generator

Type 3 uses invisible characters. Most login forms will accept it, but some may reject or mangle it. If a site rejects your new password, switch back to Type 1 or 2 and generate again.

⚠️ Setting either minimum above 0 slightly reduces entropy (some positions become predictably "at least this many digits / special chars" instead of fully free choice). Leave both at 0 for maximum entropy; raise them only if a specific site requires it. "Classic special characters" means standard ASCII punctuation (! @ # $ % ^ & * ( ) - _ = + [ ] { } | ; : ' " , . < > / ? etc.) — available at every complexity level, including Type 3.

⚠️ This extension cannot detect or verify whether Firefox actually saved your password — there is no WebExtension API for that. This checkbox is just a personal reminder. Please confirm the save yourself, e.g. via the "Save Login?" prompt after submitting the form, or under Settings → Privacy & Security → Logins and Passwords.

TrueGen never stores, transmits, or logs the passwords it generates. Each password is created locally and written directly into the field you had focused — it exists only in your browser's memory and, if you save it, in Firefox's own password manager.
